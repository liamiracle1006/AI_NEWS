# Skill: now

## 简介

返回当前北京时间（UTC+8）。纯 `datetime`，不调 LLM 不发请求，毫秒级响应。

## 触发词

- `现在几点` / `几点了` / `现在时间` → 完整时间
- `今天几号` / `今天日期` → 日期 + 星期
- `今天星期几` → 仅星期
- `now time` / `current time` → 完整时间

## 输入 → 输出

| 用户发 | bot 回 |
|---|---|
| `现在几点` | `2026-06-11 14:30（周四）。` |
| `今天几号` | `今天 2026-06-11（周四）。` |
| `今天星期几` | `今天周四。` |

## 安全边界

- 零外部依赖
- 零 LLM 调用
- 零文件 IO
- 一行 `datetime.now()`，不可能出错
