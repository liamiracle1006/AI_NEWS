# Skill: stock_a

## 简介

A 股 / 港股 / 指数 股价查询。东方财富 push2 接口免 key 免登录，响应快。

## 触发词

- `股价`
- `股票`
- `A股` / `a股`

参数：6 位 A 股代码 / 5 位港股代码 / 中文公司名 / 指数名。

## 输入 → 输出

| 用户发 | bot 回（示例） |
|---|---|
| `茅台股价` | `贵州茅台 (600519) 1789.50 ↑+1.20%` 下一行开/高/低/昨 |
| `600519 股价` | 同上 |
| `腾讯股价` | `腾讯控股 (00700) 350.00 ↓-0.50%` |
| `上证指数` / `大盘` | `上证指数 (000001) 3245.67 ↑+0.32%` |
| `创业板` | `创业板指 (399006) ...` |
| `股价火星` | 错误提示 + 用法 |

## 工作流

1. 抽代码：先找 5-6 位数字，再查中文名映射表
2. 推断市场代码（market_code）：
   - 港股 5 位 → market=116
   - 沪市 60/68 开头 + 沪深指数 → market=1
   - 深市 00/30 开头 + 深市指数 399 → market=0
3. 调 push2 API：`secid={market}.{code}`，字段含
   f43=当前价, f44=高, f45=低, f46=开, f57=代码, f58=名称, f60=昨收, f170=涨跌%
4. 价格全部除 100（push2 返回的是分）
5. 拼成两行简洁输出

## 安全边界

- 公开数据，无任何认证
- 5 秒超时
- 失败兜底友好提示
- 中文名映射表是白名单（避免脏字符进 URL）
- **不做投资建议** — 仅查行情，不预测、不推荐买卖
